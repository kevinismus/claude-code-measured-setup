# Global instructions

My defaults for every project.

## Keeping this file current

- You maintain this file. It starts nearly empty on purpose; let it grow from real work.
- Add a line when I correct you, state a lasting preference, or you hit a non-obvious fact about my machine or tools that would cause a mistake in another project. Knowledge about one project goes in that project's CLAUDE.md instead.
- Keep a line only if removing it would cause a mistake in a future session. Before adding one, look for a line that already covers it and edit that instead. Delete lines that turn out wrong or stale, and merge overlapping ones.
- One instruction per bullet, under a header. The file loads into every session, so keep it short: put long procedures in an on-demand file and name it here by path.
- Make the edit without asking, then tell me in one line what changed and why.

## Reports

- Keep final reports short: outcome, actions I must take, risks. Give detail only when I ask.
